# Third-Party ADR Materials

The benchmark code and original documentation are licensed under the repository
MIT License. The ADR texts under `results/adrs/` were written by third parties
and remain subject to the licenses and copyright notices of their source
repositories.

The reviewer package contains 162 evaluated ADRs and four additional ADRs named
as held-out records in the frozen evaluation manifest. Each ADR JSON file records
its source repository, source URL, retrieval timestamp, and frozen text. The
release manifest supplies a SHA-256 hash for every distributed file. The
machine-readable repository-level license inventory is
`release/source_licenses.json`.
